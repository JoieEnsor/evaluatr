# Package index

## Secure validation

Retrieve model specifications and generate predictions without exposing
model coefficients or patient data.

- [`secure_model_validation()`](https://joieensor.github.io/evaluatr/reference/secure_model_validation.md)
  : Secure Model Validation
- [`list_registered_models()`](https://joieensor.github.io/evaluatr/reference/list_registered_models.md)
  : List models registered in the evaluatr public directory
- [`register_model()`](https://joieensor.github.io/evaluatr/reference/register_model.md)
  : Register a model and generate its protected specification file
